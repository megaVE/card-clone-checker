# Card Clone Checker

EN: Small application for fake validation of "card cloning"

PT: Pequena aplicação para validação fictícia de "clonagem de cartão" 

## Features

- Real Credit Card Type checking with the library "credit-card-type" (Checagem real de bandeira de cartão com a biblioteca "credit-card-type")
- Custom Card Colors (Customização de Cores do Cartão)
- CSS Card with User-provided data (Cartão CSS com os dados providos pelo usuário)
